# 超雄 V70 全能导演 Skill

把剧本、人物、场景、道具、空间、摄影、声音、AI 视频提示词与质检返修组织为完整的影视制作流程。

## Skill 文件

完整技能目录：[skills/chaoxiong-director](skills/chaoxiong-director)。

在 GitHub 页面选择 **Code → Download ZIP** 下载整个仓库，解压后使用 `skills/chaoxiong-director` 文件夹。将该文件夹交给所用客户端的 Skill 安装器，或放入该客户端支持的技能目录；导入能力以客户端当前版本为准。本仓库地址用于下载文件，不代表 ChatGPT 一键安装链接。

## 内容

- 完整保留用户 V68 生产正文及 V2 人物、场景资产母版。
- 十四类任务路由：剧本创作与修改，人物、场景、道具、静态分镜，视频提示词，风格参考，模型转译，接戏，质检返修，封面文案，工具整合与模型更新。
- 六类生成方式：组内切镜、逐镜生成、控制增强、连续长镜、后期修复、图片资产。
- 正式视频输出按十四字段：全局核心要求、前缀、组头、关联剧情、出境人物、场景、道具、绝对空间锚点（POS）、影视级光线摄影、影视级音效，声音、对白资产、分镜组、完整后缀、负面提示词。
- 台词原文、归属及口型所有权核销；每组独立 START；跨组零尾帧依赖。

## 使用示例

安装后可要求：

> 使用超雄 V70，把我提供的剧本转换为 16:9 真人电影写实分镜提示词。每组最多 15 秒，组内允许切镜，十四字段完整输出，原台词逐句保留。

纯剧本、图片资产与一镜到底使用对应路由，不强行套用其它任务的字段。

## 验证

32 项结构回归测试及纯剧本、静态分镜、组内切镜、30 秒一镜到底四类文本试用已完成。结构校验不等于实际视频成片验收。技能本身不包含视频模型、账号或额度。
