# 创作、审剧与资料改编

先确定用户要求：纯剧本、梗概、集纲、分析、改稿、续写或小说影视化。纯剧本保留正常场景标头、动作与对白，不添加时间码、分镜、模型信息、制作评语或总结。用户要文档时按宿主文档能力生成并保存，不能用聊天节选冒充全文。

完整读取已有剧本与角色/世界设定，建立事实、人物欲望、阻力、选择、后果、信息揭示和未解决线索。分析指出具体场景、可拍问题及影响；用户只要分析时不自动改写。改稿先圈定授权范围；完整改稿按最终版本检查前后因果、出场来源和伏笔回收，不能只润色高光段。

原创剧本用可拍动作和对白推动变化，让角色通过选择承担后果。强开场来自具体异常、困境、问题或利益冲突；反转必须由已铺线索和人物动机支撑。高潮和钩子服务用户题材，不强迫所有现实主义、纪实或情感项目都使用夸张爽点。系列记录角色弧、单集事件、长期暗线、已揭示信息与下一集入口，续写不重复上一集结果或突然重置关系。

设计时长应由对白自然演读、行动、停顿与场景转换预算支撑。90分钟电影不能仅靠标题写90分钟；45集、60集或完整120秒任务必须覆盖明确范围。分批输出写已完成与下一游标，不能把未写部分标为完成。原著/原剧本转译不能丢事件或以删句适应模型时长。

真实案例按资料事实表达；资料未记载的提醒、争执、异响、预兆、迟疑、心理判断不能作为真实事件补入。新增导演动作仅能帮助表达既有事实，不能增加因果。需要假设或创作则明确标为方案并等待相关事实确认，不把未知写成史实。

影视化把心理落到视线、停顿、呼吸、重心、手指、距离、声音与环境反馈；文学心理词可留在剧本分析层，但模型执行层必须可观察。一个镜头允许围绕一个主要叙事任务的自然动作链，不将每次眨眼或伸手都拆镜。
