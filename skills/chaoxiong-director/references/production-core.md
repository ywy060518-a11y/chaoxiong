# 生产真值、优先级与状态

R0：当前用户明确任务、授权和锁定事实。R1：未经授权不得改变的原剧本、原资料、身份、因果和不可逆事实。R2：本版格式、路由、台词完整性、空间连续性与项目确认的核心资产。R3：本次导演设计、参考职责与视觉表达。R4：模型偏好、风格默认与方便性。R 层级用于冲突裁决，不代表模型必然执行。

C0：剧情、原台词、身份、角色数量、授权、物理可能性与不可逆状态。C1：参考身份、服装、站位、场景拓扑、道具、光线、构图等视觉强约束；达到确定结果需控制与验收。C2：焦段观感、节奏、快门观感、风格等导演意图；不支持物理控制时转成可见结果或后期执行。

E0：真值、台词、身份、授权或关键连续性失败，拒绝正式交付。E1：影响叙事、识别或空间的视觉失败，修复后复验。E2：不改变剧情的局部表现或技术瑕疵，按交付要求处理。严重度取决于结果影响，不机械由 C 数字推导。

列出 SOURCE（原文可查）、INTERPRETATION（导演解读）、PROPOSAL（新设计）、USER-ACCEPTED（已确认）。原资料含未知或矛盾时指出问题；不得用新细节补成伪事实。用户授权创作或改写时可以设计新剧情，但记录新版本，不伪称来自原资料。

项目圣经记录题材、媒介、画幅、语言、时代地域、风格色彩、生产约束与验证日期。冻结角色身份和场景拓扑；剧情状态另建版本。导演选择可优化，不能无声修改核心锁定。使用来源 ID 与用户原命名，不把阿拾、校园、战争项目之间的默认混用。

每个 PID 记录值、作用域、C 等级、来源、可见验收点、承载者（文本/真实绑定参考/工具设置/后期）、当前状态 Executed/Carried/Authorized、失败处理。三个状态互斥且覆盖全集，授权有证据，结转有去向。N=E+C+A 不代表已生成视频；Executed 在提示词阶段仅指要求已分配，成片阶段必须另核实结果。
