# 正式分镜十四字段规范

执行区自包含，START/END为复制边界。以下顺序固定；默认中文和用户项目画幅。每项填确定值，不留问号、占位符、备选焦段或“同上”。非适用项明确关闭或无事件，不删标题。

| 标题 | 必须写清 |
|---|---|
| 【全局核心要求】 | 风格、剧情/台词真值、身份、物理、独立起手与当前不可改变项；首行不插入时长 |
| 【前缀】 | 模型真实入口、路由与调用粒度、画幅语言、源运动/交付FPS、冻结版本、真实参考绑定及职责、完整独立START |
| 【组头】 | 项目/集/场/G/CALL/镜号、G总剪辑时长、CALL素材时长、素材入出点与剪辑范围、台词范围 |
| 【关联剧情】 | 原剧情节点、已知信息、镜头目的与新增信息；导演提案不冒充原剧情 |
| 【出境人物】 | 准确人数、逐人姓名/ID/年龄/身份/脸发体型/服装鞋饰及状态、初始姿势、必要异步反应 |
| 【场景】 | LOC版本、时代地点时段天气、建筑材质、固定物、真实光源与初态 |
| 【道具】 | PROP版本、数量形态材质尺度、持有人左右手或位置、完损/开闭/方向、证据与初态 |
| 【绝对空间锚点（POS）】 | 永久12/3/6/9点和地面锚点、逐人脚点层级/身体头向/视线/距离/路径、独立CAM与轴线侧、当前画面左右与方向 |
| 【影视级光线摄影】 | 景别焦段观感、机高机距角度、固定或运镜路径方向速度、焦点景深、来源光永久方向、色温曝光反射色彩及可读暗部 |
| 【影视级音效，声音】 | 环境底声、近远声源方位/混响、同步动作音时间、对白旁白音乐关系、声桥与音乐开关 |
| 【对白资产】 | DIA原文/说话人/原顺序/AUD槽/演读时间/画内外/口型所有权/G-S映射及跨镜字位时间；无对白明确DIA为空且无口型 |
| 【分镜组】 | S编号、本地/全片剪辑时间、Camera、Start→Action→End、表演异步反应/受力反馈、声音DIA、切出触发/匹配/合法入点 |
| 【完整后缀】 | 保护头尾、人物持物场景末态、剪辑落点、技术交付、七层验收、DIA/PID去向、项目状态增量、下一组独立起手事实 |
| 【负面提示词】 | 当前相关的身份数量、结构空间、道具文字、时代和成像禁项，不堆无关风险 |

逐镜用 `【S01｜00:00.000—00:03.000】` 等真实时间窗，保留已有项目编号。摄影写Camera与组级覆盖；表演写进入状态、谁先动/身体部位/路径接触、对手旁人反应、微表演物理反馈与End；声音写DIA原文或确定映射、口型和环境动作音时间；切出写信息或动作触发、匹配变量与合法入点。A明确硬切，B仅写后期切出且CALL不执行切镜，D写镜内节拍与稳定结束。

十一环用于检查理解与连续性，不机械堆字段；简单动作可紧凑表达，必要因果、旁人反应、持物声音末态不能省。

十四字段是正式执行卡。平台长度或分离槽限制时建立同组投喂文本和设置/参考映射，完整母稿仍保留；每个PID映射到文本、真实参考、设置或后期。用户只要可生成版时在十四字段内紧凑编译有效信息，不把内部审计长表塞进输入。跨组完整继承物理状态并重新建立START，不用承接词替代事实。
