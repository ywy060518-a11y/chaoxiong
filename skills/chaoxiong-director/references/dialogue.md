# 对白、音频槽与口型

先逐句建立不可变 source_dialogue，再拆G/S。每句DIA拥有ID、场景、原序号、说话人、听者、原文、语义节拍、音频槽、自然演读时长及来源。停顿与呼吸可导演，原词、说话人、顺序不能因镜头容量偷偷改动。

ledger 每个ID必须唯一进入 Executed、Carried、Authorized。E是本次已分配执行；C是明确结转的去向；A是用户授权的删改/合并/重复，须保留授权记录。N=E+C+A；Missing=0；未经授权重复D=0；顺序和声音归属错误O=0。完整一集或全片交付不能有Carried；分批结转保存下一DIA和目标组。模板空白、清单中的待执行不能当E。

每个AUD槽记录开始结束、轨道、声音拥有者、画内/画外、口型所有者、DIA片段字位、母轨ID和素材切片。多人轮流对白可多槽；同步对白必须原剧情允许、单独轨道并可辨识，不能把同一音频指定给两个嘴。旁白有音频拥有者但没有画内口型。反应镜中的听者闭口或执行剧情中的非说话表情。

B路由跨镜一句对白先冻结连续音频母轨，再切本CALL需要的片段；字位区间连续、不重叠、不漏字，重组等于原文。两次出现同DIA可以是合法相邻子片段，不能当整句重复；区分完整重播与切片。音频开始或结束跨S边界是合法声桥，时间在G或全片母时间线上记录，不能让每镜从整句第一字重播。

自然演读时间未实测时写“预计”，不要冒称已测。长句可跨切镜，反应镜承载画外声音；不能压缩句子或无授权倍速。平台原生音频、外部配音、口型修复和后期混音分别编译，实际不支持音频输入的入口不能写假绑定。

无对白明确DIA=[]，本组无台词口型；环境、动作与音乐仍独立设计。生成结果的台词验收用实际听审/转录比对原文，自动转录可能误识，重要差异需人工听审；文本总账通过不等于真实语音已通过。
