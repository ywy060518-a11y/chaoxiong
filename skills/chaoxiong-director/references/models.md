# 模型档案与编译

对每个实际模型记录 provider、model/version、frontend/入口、核验日期与来源、输入模态、参考数量职责、素材时长选项、画幅分辨率、原生切镜、音频输入/原生音频/口型、首尾帧、延长、姿态深度遮罩、局部编辑、提示词长度及真实导出FPS。每项能力状态：verified-docs、verified-interface、verified-test、unknown或unsupported；来源和观察层级不能混用。

不固定“最强模型”排名，不从名称推版本；模型推荐、当前价格、当前上限或API执行需查当前官方文档。已有目标和入口优先；未知且不影响视觉设计时先给模型中性方案。只有具体API或控制语法无法正确执行时才收集必要入口信息。不得因提示词任务无入口而阻塞整份导演母稿。

## 已核验的窄事实

核验日期2026-10-06；事实仅来自对应官方页面，不代表用户账号入口已开放全部能力。

- Seedance 2.0 官方页面说明文本、图像、音频与视频输入及联合音视频生成：https://seed.bytedance.com/en/seedance2_0 。具体素材数量、时长与导出参数仍按实际入口或当前文档核验。
- Seedance 2.5 官方页面说明单次最长30秒、参考视频理解、编辑与专业控制：https://seed.bytedance.com/en/seedance2_5 。这不自动证明账号入口支持30秒或每次能可靠切镜；上线能力与成片稳定性分开验收。
- Kling、Veo、MiniMax及其它模型在本包不预填未核验版本、参考数和最长时长；使用时查其实际入口与当前官方文档，不把旧资料的数字当现行规格。
- LTX官方代码提供关键帧插值、音频驱动及指定区间重生成等不同管线：https://github.com/Lightricks/LTX-2 。是否可用取决于实际安装、模型文件和运行条件，不假装宿主已接入。

## 编译顺序

原资料和锁定事实 → 完整导演母稿 → 真实输入职责 → 时间/路由 → 可见动作与声音 → 模型支持的设置或自然语言 → 短负面约束 → 参数归属回执。

输入图像使用真实ID或可访问路径，音频使用真实文件/槽，参考名与工具字段对应；不存在的@image1不能冒称实际上传。机距、焦段、FPS、快门、光圈若入口不可控制，保留用户意图并译成透视、景深、运动模糊和动作可读性；不要声称数值精确执行。

长提示词超限时去除重复形容，保留当前有效事实；参考承载的外观可压缩但必须有真实绑定。仍超限则按路由拆调用或分离设置，不能删DIA、身份、唯一动作、POS、持物与末态。不同模型只改语法、输入与控制，不改剧情。

提交前用低成本代表性镜头检查身份、站位、持物、多人口型、切镜、声音与导出格式；无测试写未知并保守执行。动态更新只改有新证据的档案和适配器，技能安装本身不安排周期研究。
