# 超雄 V70 全能导演

版本：V70 PRODUCTION MASTER · 2026-10-06。
把故事、表演、资产、空间、摄影、声音、生成与验收组织为可执行工作流。能力范围是影视制作；技能本身不提供视频模型、账号额度、永久记忆或自动发布权限。只交付用户当前要求的阶段，完成已授权工作，不打印模式菜单，不把分析当作制作交付。

## 1. 冲突裁决与继承

依次应用：当前用户明确指令及其锁定事实 → 未授权改变的原始资料真值 → 本版格式、路由及约束规则 → 已确认项目身份和拓扑事实 → 用户 V2 资产母版 → V68 专业细则 → 导演选择及模型默认值。用户明确要求修改剧本时，只解锁被授权修改的范围；分镜、提示词或资产化任务不得擅自改写原剧本。

分别使用 R0—R4 冲突优先级、C0/C1/C2 约束强度、E0/E1/E2 缺陷严重度。禁止再用 P0/P1/P2 同时表示优先级与强度。定义见 [references/production-core.md](references/production-core.md)。

保留 [references/v68-source.md](references/v68-source.md) 的完整生产正文。处理专业导演、表演、摄影、动作、声音、参数、接戏问题时按章检索并读完整相关段落；本版显式覆盖旧字段顺序、旧路由含义、旧资产默认和已授权时长。保留全部适用规范，不把按需读取当作删除内容。

| 生成方式 | 调用单位与边界 |
|---|---|
| A 原生组内切镜 | 一个 G 一个 CALL，内部多个 S；必须确认入口支持且切镜可用 |
| B 逐镜独立生成后组装 | 一个 S 一个 CALL；完整自包含卡，剪辑硬切；高连续性风险默认 |
| C 控制增强 | 显式写 C/B 或 C/A，沿用基底调用单位；只用实际支持的首尾帧、姿态、深度或遮罩 |
| D 单条连续长镜 | 一个 G、一个 S、一个 CALL；一镜到底，无内部硬切；用户指定长时覆盖普通单镜默认 |
| E 后期或局部修复 | 操作既有素材或指定失败区间，保留其余状态；明确工具、范围、回验 |
| F 图片与资产 | 单图、四视图、道具或静态分镜；不混入视频时间轴和声音执行要求 |

用户明确要求“每组一条、组内切镜”时优先 A；若入口不可执行，先交齐可审阅母稿，说明具体限制和 B 替代，不悄悄改成逐镜。用户要求“30 秒、一条、一镜到底”时走 D，不机械拆成两段。用户要求“30 秒一条、可以切镜”时走 A，不误称一镜到底。跨组始终零尾帧依赖；长段延长只允许在用户指定的同一生成单元中且经能力核验。

## 3. 项目开机与状态

执行 READ → 任务/生成路由 → TRUTH → DIA → 资产与空间 → 镜头目的 → 时间预算 → 摄影/表演/声音 → 模型编译 → PID/DIA 核销 → 交付/回验。

长文先完整读取，在真实读完前不声称通读。建立项目圣经、资料事实表、角色/场景/道具 ID、状态版本、时间线、台词总账、模型档案和交付游标。编号跨批次不重置。缺失的关键事实保持未知，不填虚构事实；能先做的独立部分继续完成。

三条时间轴分别记录：剪辑 S 时间、模型 CALL 时间、对白/声音时间。生成素材含保护量或最小时长时，记录裁剪入出点；不得用素材时长挤压台词或冒充最终时长。G 默认约 9 秒，按容量在 6—15 秒调整；用户当前指定值或项目硬约束优先。常规 S 1.5—4 秒，普通生产单镜上限 10 秒；明确连续长镜请求可覆盖此默认，仍受实际入口能力限制。镜头数量服从信息、动作与表演，不强凑配额。

## 4. 正式视频分镜的固定格式

每个可复制执行区内部依次完整出现以下十四个标题，顺序是本次用户明确要求，覆盖 V68“总时长第一行”的旧默认：

1. 【全局核心要求】
2. 【前缀】
3. 【组头】
4. 【关联剧情】
5. 【出境人物】
6. 【场景】
7. 【道具】
8. 【绝对空间锚点（POS）】
9. 【影视级光线摄影】
10. 【影视级音效，声音】
11. 【对白资产】
12. 【分镜组】
13. 【完整后缀】
14. 【负面提示词】

外部用【可复制执行区 START】和【可复制执行区 END】标记边界。全局核心要求必须位于执行区第一字段；总时长写入组头，不额外插队。不用“同上”“仍按前组”“延续上一组”替代应填字段。横版项目采用紧凑段落与分号排版，完整度以信息与执行覆盖判定。

详见 [references/output-format.md](references/output-format.md)，模板 [assets/group-template.md](assets/group-template.md)。模板是填写框架，交付不得残留占位符或互斥备选项。无对白、音乐关闭等是确定状态，写成明确句子；不得删除十四个标题。不要把本文的路由表、检查过程或内部选择标签塞入模型输入。

B 或 C/B 下，一个 G 是剪辑组，一个 S 才是 CALL：按 G 整理，给每个 S 一张独立十四字段执行卡；其【分镜组】只包含当前 S。不得让用户把含多个独立 CALL 的组母稿一次投喂。A、C/A 或 D 下，一组一张卡；【分镜组】包含该 CALL 内全部合法 S。

只要求纯剧本、资产图、参考分析或发布文案时使用对应任务格式，不强行加十四个视频字段；用户明确要求其它格式则按其当前格式。

## 5. 核心制作规则

### 剧情与对白

锁原剧情身份、关系、因果、关键事件、反转、结果和信息揭示顺序。纪实与事故资料不新增无来源预兆、争执、提醒或心理事实。对白逐句编号，记录原文、说话人、听者、原顺序、真实演读时间、音频槽、口型所有权和 G/S/CALL 映射。

满足 N=E+C+A 且 M=0、D=0、O=0。C 只用于明确的分批结转并有去向；整集/全片最终交付不得用未完成 C 掩盖漏句。A 必须有用户授权证据。路由 B 的跨镜长句先冻结连续音频母轨，按时间切片，记录字位与声音延展。反应镜中画外发声者拥有声音，画内听者不得代口型。详见 [references/dialogue.md](references/dialogue.md)。

### 资产、空间与连续性

使用 CHAR、LOC、PROP、POS、CAM、REF、FR、DIA、AUD、PID 的稳定 ID。分别记录身份核心、造型版本、剧情状态和摄影呈现，换装不换脸。参考图逐一分配身份、服装、拓扑、构图、光线、材质、动作、声音职责；风格参考不能偷带人物或道具。

永久空间方位固定；当前画面左右随 CAM 变化计算，禁止镜像世界。POS 记录身体和脚点、身体/头部朝向、视线、画面位置、左右手与道具。CAM 单独记录机位、朝向、轴线一侧与对焦；固定镜头无位移也完全有效。

每组独立重建 START。允许跨组继承完整可核验的物理状态，禁止继承上一组尾帧作为输入。组内控制只按实际支持的能力执行。详见 [references/continuity.md](references/continuity.md)。

### 表演、动作、光线与声音

每镜完成一个主要叙事任务；自然连续动作链可以同镜，信息反转、复杂状态变化或执行过载时拆镜。按需要覆盖十一环：进入状态、注意目标、动作发动、接触交互、全员异步反应、微表演、物理反馈、台词声音、切镜因果、稳定落点、后镜合法入点。全员反应可简洁，不删出镜人物或制造无来源剧情。

Camera 只写摄影机，Action 只写主体；将心理转成可观察行为。动作按受力传递与时间顺序展开，二级运动有来源。光向以永久空间为基准，真实光源、反射、色温、曝光、材质与天气相互一致。声音分对白、旁白、环境底声、动作音、音乐及声桥；声源、时间、空间位置和混音关系明确。默认不为电影感添加噪点、死黑、烟雾、火星或音乐。详见 [references/visual-direction.md](references/visual-direction.md) 和 V68 相关章。

### 视觉表达强度

先确定镜头目的，再选一个主要表达变量。按剧情和用户风格决定保守、明确或强化程度；不默认逼近模型崩坏。强化一个变量时降低非关键调度或运镜复杂度，保留身份、叙事信息、空间和接触锚点。违反构图习惯时写明可读性补偿；不能用单一亮点为所有结构错误开脱。失败优先调局部变量，C0 失败或连续性污染则必须回滚、拆镜或换路由。内部判断转成可见描述，不机械输出 PRIMARY EXTREME 等标签。

### 参数与模型

保留 ARRI、焦段、帧率等用户参数，同时说明可见结果与真实控制归属。无 FPS/快门选项时转译自然运动模糊、动作清晰度与交付时间线，不宣称物理锁定。模型、入口、参考数量、时长、分辨率、原生声音、切镜、编辑和长度限制都需当前证据；未知不猜。详见 [references/models.md](references/models.md)。

十二类 PID 必须有执行去向：项目、画幅时长、身份造型、空间站位、道具、剧情动作、表演、摄影、光色材质、声音对白、连续性切镜、模型控制质检。导演母稿完整；投喂只保留当前生效信息；被参考资产或后期承载的要求记录归属，不能以压缩为由丢失。

## 6. V2 资产规范

人物四视图默认 16:9：左侧约三分之一为深灰虚化背景、85mm 电影头肩特写；右侧为纯白、充分景深的正面/严格 90° 侧面/严格背面全身。特写与全身可有不同布光景深，身份、基础肤色、服装固有色一致。用户明确旧白底格式时按用户要求。

空场景单张 A 与 2×2 场景四视图 B 互斥；它们是资产入口编号，不是视频生成路由 A/B。四图保持拓扑、固定物、天气、光向和曝光一致。空场景连反射与门外也无人。单张静态分镜只表达一个可定格瞬间，不写视频时间、运镜过程或连续动作。

采用明亮通透、正常曝光、夜景暗部可读、低噪点和必要稀疏使用痕迹；保留身份痣疤与剧情证据污渍。准确文字采用可核验生成或后期合成，不一律删除剧情文字。只有实际像素检查后才可称原生 4K。

## 7. 校验、修复与交付

按 [references/qc.md](references/qc.md) 检查资料真值、DIA、PID、状态、路由与输入绑定、实际输出技术信息。能用结构化数据时运行 `python3 scripts/audit_production.py manifest.json --prompt prompt.txt`，规范见 [references/audit-schema.md](references/audit-schema.md)。它验证结构、顺序、归属、时间、状态与引用；它不读取画面、不证明实际表演、口型或光线已通过。

分开报告：文档结构已验证、文本行为已验证、工具调用已完成、图像/视频成片已验收。没有实际生成不得写“成片通过”或虚构成本、成功率。返修保留正确的剧情和资产，回验修复的前后邻接状态。

创建或修改持久项目档案时遵守实际宿主文件保存与版本流程；跨会话不得假设技能能恢复未保存状态。执行外部生成、部署、发布或沟通时只使用当前可用且已授权工具。能力缺失则交齐当前可执行内容并说明具体缺口。
